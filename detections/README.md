# C09 detections

Seven supplied production-form searches for Splunk index `c09`. Saved-search time
ranges are relative to dispatch time; D1, D2, D3a and D6 use fixed `bin` buckets
inside those ranges, rather than continuously sliding threshold calculations.
The scope column below describes the exact grouping: not every rule groups only
by source IP. ATT&CK mappings describe suspicious activity, not proof of compromise.

| ID | Name | Logic summary | Threshold | Confidence | ATT&CK | CWE |
|---|---|---|---|---|---|---|
| [D1](D1_password_guessing.spl) | Password guessing | At least five auth failures for one account and source endpoint in a 5-minute bin. | 5 failures / 5m / source endpoint + account | High | T1110.001 | none |
| [D2](D2_password_spraying.spl) | Password spraying | At least five distinct accounts fail from one source IP in a 5-minute bin. | 5 distinct accounts / 5m / src_ip | High | T1110.003 | none |
| [D3a](D3a_multi_endpoint_auth.spl) | Multiple successful authentications from distinct endpoints | One account authenticates successfully from at least two source ports in a 10-minute bin. | 2 source ports / 10m / user_ref | High | none | none |
| [D3b](D3b_concurrent_sessions.spl) | Probable concurrent game sessions for one account | Carry user_ref from successful auth onto endpoint game events; +1 join / -1 timeout per account; fire at live_sessions >= 2. | 2 concurrent sessions / account within 10m search | Probabilistic | none | none |
| [D4](D4_unauth_game_join.spl) | Game join without observed matching handoff | Game join has no matching source-endpoint handoff in the prior five minutes. | 1 unmatched join / prior 5m / source endpoint | Medium | none | CWE-306 |
| [D5](D5_unauth_master_action.spl) | Master action without prior authentication | Lobby creation or handoff is observed with authenticated=false. | 1 unauthenticated action / 5m search / source endpoint | High | none | CWE-306 |
| [D6](D6_lobby_creation_burst.spl) | Lobby creation burst | At least ten lobby creations from one source IP in a 1-minute bin. | 10 creates / 1m / src_ip | Medium | T1499.003 (conditional) | CWE-770 |

## Validation

The lab operator reports all seven detection scenarios validated on **2026-10-14**
against isolated case windows generated by [phase3/attack/](../phase3/attack/):
positive fired with the expected number, negative silent. Pinned case windows
were the validation source of truth; the generator's default eight-second gaps
do not isolate the longer detection lookbacks.

| ID | Expected positive evidence | Negative result reported |
|---|---|---|
| D1 | 6 failed authentications | Silent |
| D2 | 6 distinct failed accounts | Silent |
| D3a | 2 successful source endpoints | Silent |
| D3b | live_sessions=2 with the corrected account-correlated SPL | Silent |
| D4 | 1 game join with no master handoff | Silent |
| D5 | 1 unauthenticated lobby creation | Silent |
| D6 | 15 lobby creations | Silent |

These numbers describe the supplied scenario evidence, not the number of returned
SPL rows. Live Splunk was not queried during packaging. The lab operator reports
the corrected account-correlated D3b production form validated in Splunk on
2026-10-14 against the saved isolated case windows: positive fired
(`live_sessions=2`), negative silent.

The `.spl` files begin with `#` documentation lines. Remove those lines when
pasting into Splunk Search; `#` is not SPL comment syntax. The saved-search config
already contains only executable search text.

## Limitations

- Thresholds are lab-tuned and primarily per-IP; all lab traffic shares one source
  IP. D1 additionally groups by source port and account, so distributing guesses
  across ports splits its counts. D3a counts ports, not full IP:port endpoints,
  which only matches the one-source-IP lab assumption.
- Pinned case windows were the validation source of truth. Fixed bucket boundaries
  can split a burst; relative dispatch windows can omit earlier correlation events.
- Production D3b/D4 correlation is heuristic: the protocols carry no shared
  account identity, and endpoint reuse, NAT, missing telemetry or a separate game
  socket can invalidate the inferred link. D4 compares only source endpoints, not
  the handoff's destination game IP/port. A five-minute dispatch can omit a handoff
  preceding a join near its lower boundary.
- D3b carries account identity from successful auth by source endpoint and counts
  joins/timeouts per account. Its ten-minute dispatch includes the timeout tail;
  accurate counts still require the relevant auth, join and timeout history.
- D6 indicates a suspicious burst, not proven denial of service. D6 negative uses
  this brief's generator spacing of about one second; the schema's validation table
  describes a different five-minute negative scenario.
- Compare account hashes only within one HMAC key generation. The supplied account
  searches do not group by `user_ref_key_id`; avoid mixing rotations in a window.
